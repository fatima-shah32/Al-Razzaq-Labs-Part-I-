# Lab 18: Numerical Operations in Bash

## Objective

Learn how to perform arithmetic calculations in Bash using both built-in arithmetic expansion and the bc utility.

## Tasks Completed

### Task 1
Accepted two numbers from the user.

### Task 2
Performed addition operations.

### Task 3
Performed subtraction operations.

### Task 4
Performed multiplication operations.

### Task 5
Performed division operations.

### Task 6
Implemented division-by-zero error handling.

## Concepts Used

- Bash Scripting
- User Input
- Arithmetic Expansion
- bc Utility
- Conditional Statements
- Error Handling
