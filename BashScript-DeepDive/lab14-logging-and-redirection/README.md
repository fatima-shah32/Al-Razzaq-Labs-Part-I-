# Lab 14: Logging and Redirecting Output

## Objective

Learn how to redirect and log output in Bash using the tee command.

## Tasks Completed

### Task 1
Created a script that prints multiple lines of text.

### Task 2
Used the tee command to display output on the console and save it to a log file.

### Task 3
Verified the log file contents.

### Task 4
Confirmed that output appeared both on-screen and in the log file.
