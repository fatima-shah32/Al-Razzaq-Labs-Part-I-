# Lab 12: Array Handling in Bash

## Objective

Learn how to create, access, iterate, and modify arrays in Bash scripting.

## Tasks Completed

### Task 1
Created an array containing fruit names.

### Task 2
Displayed all array elements.

### Task 3
Used a for loop to iterate through the array.

### Task 4
Added a new element dynamically.

### Task 5
Displayed the updated array.

## Concepts Used

- Bash Arrays
- Array Expansion
- for Loops
- Iteration
- Dynamic Array Updates

Fruits array: apple banana cherry

Fruit: apple
Fruit: banana
Fruit: cherry
