# Lab 2: Using Variables

## Objective

Learn how to define, print, and modify variables in a Bash script.

## Tasks Completed

### Task 1
Created a variable named NAME and assigned the value "Alice".

### Task 2
Displayed the variable value using the echo command.

### Task 3
Changed the variable value to "Bob" and printed it again.

### Task 4
Made the script executable and executed it successfully.

## Concepts Used

- Variables
- String Assignment
- echo Command
- Bash Scripting
- chmod +x

## Sample Output

Hello Alice!
Hello Bob!
