# Lab 8: While Loop Basics

## Objective

Learn how to use a while loop in Python to repeatedly execute code while a condition remains true.

## Tasks Completed

### Task 1
Initialized a counter variable.

### Task 2
Implemented a while loop using a conditional expression.

### Task 3
Printed the counter value during each iteration.

### Task 4
Incremented the counter to control loop execution.

### Task 5
Verified loop termination after the condition became false.

## Concepts Used

- While Loop
- Counter Variable
- Conditional Expressions
- Iteration
- Python Scripting
