# Lab 4: Command-Line Arguments

## Objective

Learn how to pass and process command-line arguments in Bash scripts.

## Tasks Completed

### Task 1
Created a Bash script that accepts command-line arguments.

### Task 2
Displayed personalized greetings using positional parameters.

### Task 3
Handled multiple arguments using a loop.

### Task 4
Implemented error handling when no arguments are supplied.

### Task 5
Tested the script with different inputs.

## Concepts Used

- Command-Line Arguments
- Positional Parameters ($1, $@)
- Argument Count ($#)
- for Loop
- Conditional Statements
- Error Handling

## Sample Outputs

### No Arguments

Error: No arguments supplied
Usage: ./greet.sh <name1> <name2> ...

### Single Argument

Hello, Alice!

### Multiple Arguments

Hello, Alice!
Hello, Bob!
Hello, Eve!
