# Lab 13: Command Substitution

## Objective

Learn how to use command substitution in Bash scripts to capture and store command outputs in variables.

## Tasks Completed

### Task 1
Stored the current date using the date command.

### Task 2
Stored the current username using whoami.

### Task 3
Stored the current working directory using pwd.

### Task 4
Stored the Linux kernel version using uname -r.

### Task 5
Displayed all stored values using echo.

## Concepts Used

- Bash Scripting
- Variables
- Command Substitution
- date
- whoami
- pwd
- uname
