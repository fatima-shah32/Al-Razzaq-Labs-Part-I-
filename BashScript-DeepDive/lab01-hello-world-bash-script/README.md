# Lab 1: Hello World Bash Script

## Objective

Learn how to create, make executable, and run a basic Bash script.

## Tasks Completed

- Created a Bash script file named hello.sh
- Added the Bash interpreter directive (shebang)
- Printed "Hello World!" using the echo command
- Made the script executable using chmod
- Executed the script successfully

## Concepts Used

- Bash scripting
- Shebang (#!/bin/bash)
- echo command
- chmod +x
- Script execution

## Sample Output

Hello World!
