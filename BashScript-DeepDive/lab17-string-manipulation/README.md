# Lab 17: String Manipulation in Bash

## Objective

Learn how to perform common string manipulation tasks in Bash scripting.

## Tasks Completed

### Task 1
Accepted a string as user input.

### Task 2
Calculated and displayed the length of the string.

### Task 3
Extracted a substring from the input string.

### Task 4
Replaced occurrences of "abc" with "xyz".

### Task 5
Tested all string operations successfully.

## Concepts Used

- Bash Scripting
- User Input
- String Length
- Substring Extraction
- String Replacement
- Parameter Expansion
