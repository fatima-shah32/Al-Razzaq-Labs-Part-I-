# Lab 20: Creating a Bash Menu Interface

## Objective

Learn how to create an interactive menu-driven Bash script using loops, functions, and case statements.

## Tasks Completed

### Task 1
Created an interactive Bash menu.

### Task 2
Used a while loop to continuously display the menu.

### Task 3
Captured user input using the read command.

### Task 4
Implemented a case statement for menu navigation.

### Task 5
Created functions for displaying date, listing files, and exiting the script.

### Task 6
Tested all menu options successfully.

## Concepts Used

- Bash Scripting
- Functions
- while Loop
- case Statement
- User Input
- Linux Commands
- Menu-Driven Interface

## Sample Menu

====================
 Bash Menu Interface
====================
1. Show date
2. List files
3. Exit
