# Lab 15: Basic Error Handling

## Objective

Learn how to implement basic error handling in Bash scripts by checking directory existence and using exit codes.

## Tasks Completed

### Task 1
Created a script to check if a directory exists.

### Task 2
Displayed success messages when the directory was found.

### Task 3
Displayed clear error messages when the directory was missing.

### Task 4
Used exit codes to indicate script failure.

### Task 5
Tested both success and failure scenarios.

## Concepts Used

- Bash Scripting
- Conditional Statements
- Directory Validation
- Error Handling
- Exit Codes
- User-Friendly Messages

## Sample Output

Directory exists.

Error: Directory does not exist.
Please create the directory before proceeding.
