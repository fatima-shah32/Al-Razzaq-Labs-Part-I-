# Lab 3: Accepting User Input

## Objective

Learn how to accept user input in a Bash script using the read command and display personalized output.

## Tasks Completed

### Task 1
Created a Bash script named greet_user.sh.

### Task 2
Prompted the user to enter their name.

### Task 3
Captured user input using the read command.

### Task 4
Displayed a personalized greeting using the entered name.

### Task 5
Made the script executable and executed it successfully.

## Concepts Used

- Bash scripting
- User Input
- read command
- Variables
- echo command
- chmod +x

## Sample Output

What is your name?
Alice
Nice to meet you, Alice!
