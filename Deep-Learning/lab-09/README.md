# Lab 09: CNN for MNIST Digit Recognition

## Objective

Build, train, and evaluate a Convolutional Neural Network using TensorFlow/Keras on the MNIST dataset.

## Tools Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Dataset

MNIST handwritten digit dataset.

## Tasks Performed

1. Loaded MNIST dataset
2. Normalized image pixel values
3. Reshaped images for CNN input
4. One-hot encoded labels
5. Built CNN model using Conv2D and MaxPooling2D
6. Trained the model
7. Evaluated test accuracy
8. Saved model, plots, and report
