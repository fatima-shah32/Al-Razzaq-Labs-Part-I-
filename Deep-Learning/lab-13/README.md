# Lab 13: Saving and Loading Deep Learning Models

## Objective

Learn how to save and load deep learning model architecture and weights.

## Tools Used

- Python
- TensorFlow
- Keras
- NumPy
- HDF5

## Tasks Performed

1. Created a simple neural network model
2. Saved model architecture as JSON
3. Saved model weights in HDF5 format
4. Reloaded model architecture from JSON
5. Restored model weights
6. Compared predictions from original and loaded models
7. Generated report
