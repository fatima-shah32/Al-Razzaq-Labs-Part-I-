# Lab 40: Final Deep Learning Project

## Objective

Develop a complete end-to-end deep learning application using TensorFlow and CNNs.

## Dataset

CIFAR-10 Image Classification Dataset

## Problem Statement

Classify images into 10 categories:

- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

## Tools Used

- Python
- TensorFlow
- NumPy
- Matplotlib
- Scikit-Learn

## Workflow

1. Load CIFAR-10 Dataset
2. Normalize Images
3. Build CNN Model
4. Train Model
5. Evaluate Performance
6. Save Trained Model
7. Generate Accuracy and Loss Graphs
8. Create Project Report

## Files

```text
final_deep_learning_project.py
README.md
project_report.txt
accuracy_plot.png
loss_plot.png
cifar10_cnn_model.keras
```

## Results

The CNN model successfully classified CIFAR-10 images and achieved good accuracy on unseen test data.

## Conclusion

This project demonstrated a complete deep learning workflow from dataset preparation to model deployment artifacts and reporting.
