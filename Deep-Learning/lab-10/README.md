# Lab 10: Visualizing Training History

## Objective

Learn how to record, visualize, and analyze model training history using TensorFlow/Keras.

## Tools Used

- Python
- TensorFlow
- Keras
- Matplotlib
- Pandas

## Dataset

MNIST handwritten digit dataset.

## Tasks Performed

1. Loaded MNIST dataset
2. Normalized image data
3. Built a simple neural network
4. Trained model for 10 epochs
5. Recorded training history
6. Plotted training and validation loss curves
7. Plotted training and validation accuracy curves
8. Saved CSV and report files

Conclusion
