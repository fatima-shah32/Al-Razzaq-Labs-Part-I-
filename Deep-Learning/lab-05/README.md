# Lab 05: Exploring Activation Functions

## Objective

Understand and compare ReLU, Sigmoid, and Tanh activation functions in small neural networks.

## Tools Used

- Python
- TensorFlow
- NumPy
- Pandas
- Matplotlib

## Tasks Performed

1. Created random training data
2. Built a neural network using ReLU
3. Built a neural network using Sigmoid
4. Built a neural network using Tanh
5. Trained all models for 10 epochs
6. Compared training losses
7. Saved predictions, plot, and report

Conclusion

This lab showed how activation functions affect neural network training behavior. ReLU often learns faster, Sigmoid can suffer from vanishing gradients, and Tanh can perform better than Sigmoid in some cases because it centers values around zero.
