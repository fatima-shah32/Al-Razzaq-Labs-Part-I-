# Lab 11: Model Evaluation Using a Confusion Matrix

## Objective

Evaluate a classification model using a confusion matrix and classification metrics.

## Tools Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

Iris dataset from scikit-learn.

## Tasks Performed

1. Loaded Iris dataset
2. Split data into training and testing sets
3. Trained DecisionTreeClassifier
4. Generated predictions on test data
5. Created confusion matrix
6. Visualized confusion matrix using Seaborn
7. Generated classification report
8. Saved analysis report
