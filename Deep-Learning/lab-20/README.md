# Lab 20: CNN for Basic Image Classification

## Objective

Build, train, and evaluate a Convolutional Neural Network for image classification using CIFAR-10.

## Tools Used

- Python
- TensorFlow/Keras
- NumPy
- Pandas
- Matplotlib

## Dataset

CIFAR-10 image dataset.

## Classes

- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

## Tasks Performed

1. Loaded CIFAR-10 dataset
2. Normalized image data
3. One-hot encoded labels
4. Built CNN model using Conv2D and MaxPooling2D
5. Trained the CNN model
6. Evaluated test accuracy
7. Saved training plots and sample predictions
8. Saved trained model and report
