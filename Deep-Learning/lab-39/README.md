## Objective

Understand the concept of Capsule Networks and implement a simplified CapsNet for image classification.

## Dataset

MNIST Handwritten Digits Dataset

## Tools Used

- Python
- TensorFlow
- NumPy
- Matplotlib

## Workflow

1. Load MNIST Dataset
2. Normalize Images
3. Build Simplified Capsule Network
4. Train Model
5. Evaluate Performance
6. Visualize Predictions
7. Save Model

## Results

The simplified Capsule Network successfully classified handwritten digits and achieved high accuracy on the test dataset.

## Conclusion

Capsule Networks preserve more spatial information than traditional CNNs and provide an alternative architecture for image classification tasks.
