# Lab 31: Basic Data Augmentation using Python

## Objective

The objective of this lab is to understand data augmentation and apply basic image and text augmentation techniques using Python.

## Introduction

Data augmentation means creating new training samples by making small changes to existing data.

It helps improve model generalization, reduce overfitting, and increase dataset diversity.

## Tools Used

- Pillow
