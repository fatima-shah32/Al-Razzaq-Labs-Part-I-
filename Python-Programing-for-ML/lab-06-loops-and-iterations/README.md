# Lab 6: Python Basics - Loops and Iterations

## Objective

Learn how to use for loops and while loops in Python to automate repetitive tasks.

## Tools Used

- Python

## Tasks Performed

1. Created a list of numbers
2. Iterated through the list using a for loop
3. Used a while loop with a counter
4. Printed iteration details using enumerate()
5. Tracked loop execution with start and end messages

## Main Code

```python
for number in numbers:
    print(number)
```

```python
while count < 5:
    print(count)
    count += 1
```

```python
for i, number in enumerate(numbers):
    print(f"Iteration {i+1}")
```
