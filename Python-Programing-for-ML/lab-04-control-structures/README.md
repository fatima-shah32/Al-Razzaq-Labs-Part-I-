## Main Code

```python
if temperature > 25:
    print("It's a warm day!")
elif temperature > 20:
    print("It's a mild day!")
else:
    print("It's a cool day!")
```

```python
for i in range(5):
    print(i)
```

```python
while counter < 5:
    print(counter)
    counter += 1
```
