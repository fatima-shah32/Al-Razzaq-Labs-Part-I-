# Lab 19: Simple Model Persistence Save & Load

## Objectives

- Understand model persistence
- Train a machine learning model
- Save model using joblib
- Load saved model
- Make prediction using loaded model

## Tools Used

- Python
- NumPy
- Scikit-learn
- Joblib

## Dataset

Iris dataset from scikit-learn.

## Tasks Performed

1. Loaded Iris dataset
2. Split data into training and testing sets
3. Trained RandomForestClassifier
4. Evaluated model accuracy
5. Saved model using joblib
6. Loaded saved model
7. Made prediction using loaded model
8. Saved report
