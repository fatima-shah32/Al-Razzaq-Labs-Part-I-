# Lab 16: Feature Scaling (Standardization)

## Objective

Learn how to standardize numerical features using StandardScaler and compare model performance before and after scaling.

## Tools Used

- Python
- NumPy
- Pandas
- Scikit-learn

## Tasks Performed

1. Created a sample dataset
2. Applied StandardScaler
3. Trained Logistic Regression on original data
4. Trained Logistic Regression on scaled data
5. Compared model accuracies
6. Generated result report

## Files

```text
feature_scaling.py
results.txt
README.md
```

## Conclusion

Feature scaling helps normalize numerical features and improves the performance of machine learning algorithms that are sensitive to feature magnitude, such as Logistic Regression, K-Means, and Neural Networks.
