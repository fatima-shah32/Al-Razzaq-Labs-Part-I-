# Lab 13: Evaluating Classification Models

## Objectives

- Evaluate classification model performance
- Generate a confusion matrix
- Calculate precision, recall, and F1-score
- Interpret model evaluation results

## Tools Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

Iris dataset from scikit-learn.

## Tasks Performed

1. Loaded Iris dataset
2. Split data into training and testing sets
3. Trained RandomForestClassifier
4. Generated predictions
5. Created confusion matrix
6. Calculated accuracy
7. Generated classification report
8. Saved metrics and evaluation summary
