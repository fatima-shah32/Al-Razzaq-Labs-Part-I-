# Lab 17: Feature Selection & Importance

## Objective

Learn how to identify important features using Random Forest and evaluate model performance after removing low-importance features.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Tasks Performed

1. Loaded Iris dataset
2. Trained Random Forest classifier
3. Calculated feature importance scores
4. Visualized feature rankings
5. Removed low-importance features
6. Compared model accuracy before and after feature selection

## Files

```text
feature_selection.py
feature_importance.png
results.txt
README.md
```

## Conclusion

Feature selection simplifies machine learning models by removing less useful features. It can reduce computation time while maintaining similar predictive performance.
