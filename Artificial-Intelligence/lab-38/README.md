# Lab 38: Deploying a Model Locally with Flask

## Objective

Deploy a trained machine learning model locally using Flask.

## Tools Used

- Python
- Flask
- Scikit-learn
- NumPy
- Pickle

## Tasks Performed

1. Created Artificial-Intelligence/lab-38 folder
2. Created a virtual environment
3. Trained a RandomForestClassifier on Iris dataset
4. Saved model as model.pkl
5. Created a Flask web app
6. Loaded model in Flask
7. Took user input from browser
8. Displayed prediction result
