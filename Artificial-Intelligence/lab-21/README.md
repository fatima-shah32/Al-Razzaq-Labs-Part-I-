## Tools Used

- Python
- TensorFlow
- Keras
- Matplotlib

MNIST handwritten digits dataset.

3. Built a Sequential MLP model

6. Trained the model for 5 epochs
7. Evaluated test accuracy
8. Saved model, plot, and report
