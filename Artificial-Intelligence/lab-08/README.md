## Short Note

### Supervised Learning

Uses labeled data to predict outcomes.

Examples:

- Spam Detection
- House Price Prediction
- Sentiment Analysis

### Unsupervised Learning

Uses unlabeled data to discover hidden patterns.

Examples:

- Customer Segmentation
- Anomaly Detection
- Market Basket Analysis

## Conclusion

This lab introduced the two major machine learning paradigms. Supervised learning focuses on prediction using labeled data, while unsupervised learning discovers patterns from unlabeled data.
