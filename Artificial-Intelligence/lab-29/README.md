# Lab 29: Text Vectorization Bag-of-Words and TF-IDF

## Objective

Understand text vectorization and compare Bag-of-Words with TF-IDF using a simple classifier.

## Tools Used

- Python
- Pandas
- Scikit-learn

## Tasks Performed

1. Created sample text documents
2. Applied Bag-of-Words using CountVectorizer
3. Applied TF-IDF using TfidfVectorizer
4. Trained Naive Bayes classifier
5. Compared accuracy of both vectorization methods
6. Saved matrices and report files

## Files Created

```text
bag_of_words_matrix.csv
tfidf_matrix.csv
vectorization_report.txt
Conclusion

In this lab, I learned how to convert text into numerical features using Bag-of-Words and TF-IDF. Bag-of-Words counts word frequency, while TF-IDF gives more importance to meaningful and less common words. I also trained a Naive Bayes classifier to compare both methods.
