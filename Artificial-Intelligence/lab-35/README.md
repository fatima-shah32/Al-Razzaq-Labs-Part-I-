# Lab 35: Handling Imbalanced Datasets

## Objective

Learn how to handle imbalanced datasets using SMOTE and compare model performance before and after balancing.

## Tools Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Imbalanced-learn

## Tasks Performed

1. Created an imbalanced binary classification dataset
2. Checked original class distribution
3. Split data into train and test sets
4. Applied SMOTE oversampling
5. Trained Logistic Regression on imbalanced data
6. Trained Logistic Regression on balanced data
7. Compared classification reports
8. Saved datasets, plots, and reports
