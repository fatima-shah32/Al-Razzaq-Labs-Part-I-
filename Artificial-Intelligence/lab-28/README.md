# Lab 28: Sentiment Analysis Concept

## Objective

Understand sentiment analysis and build a simple machine learning model to classify text as positive or negative.

## Tools Used

- Python
- Pandas
- Scikit-learn
- NLTK

## Tasks Performed

1. Created a labeled text dataset
2. Cleaned text using regular expressions
3. Split data into training and testing sets
4. Converted text into numerical features using TF-IDF
5. Trained Logistic Regression model
6. Evaluated model accuracy
7. Saved dataset and report
