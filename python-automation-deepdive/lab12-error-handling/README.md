# Lab 12: Error Handling with try-except

## Objective
Learn how to handle exceptions gracefully in Python.

## Exceptions Covered
- ZeroDivisionError
- ValueError
- Generic Exception

## Features
- User input validation
- Division operation
- Custom error messages
- Program continues safely without crashing

## Sample Cases

### Valid Input
Input: 25
Output: 4.0

### Division by Zero
Input: 0
Output: Cannot divide by zero

### Invalid Input
Input: abc
Output: Please enter a valid number
