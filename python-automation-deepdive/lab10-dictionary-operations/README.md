# Lab 10: Dictionary Operations

## Objective
Learn basic dictionary operations in Python.

## Tasks Completed

### Task 1: Create a Dictionary
Created a dictionary containing:
- Name
- Age
- City

### Task 2: Retrieve a Value
Retrieved the value associated with the key "name".

### Task 3: Update and Add Data
- Updated age from 30 to 31.
- Added occupation as a new key-value pair.

## Concepts Used

- Dictionary creation
- Accessing values using keys
- Updating dictionary values
- Adding new key-value pairs

## Sample Output

Original Dictionary:
{'name': 'Alice', 'age': 30, 'city': 'New York'}

Name: Alice

Updated Dictionary:
{'name': 'Alice', 'age': 31, 'city': 'New York', 'occupation': 'Engineer'}
