# Lab 25: Creating a Simple CLI using argparse

## Objective
Learn how to build command-line tools using Python argparse.

## Features
- --verbose flag
- --file input option
- --level selection (1-3)
- --timeout default value

## How to Run

### Basic run
python3 cli_example.py

### Verbose mode
python3 cli_example.py --verbose --file test.txt

### Set level
python3 cli_example.py --level 2

## Learning Outcome
- CLI argument handling
- Option parsing
- Input validation using argparse
