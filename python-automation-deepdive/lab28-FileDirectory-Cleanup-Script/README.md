# File & Directory Cleanup Script

## Objective
Automate deletion of old files using Python.

## Features
- Detects old files using modification time
- Deletes files older than threshold
- Logs all actions

## How it works
- Uses os module for file handling
- Uses time module for timestamps
- Uses logging for audit trail

## Output
- Deleted files are removed automatically
- Actions saved in cleanup_log.txt
