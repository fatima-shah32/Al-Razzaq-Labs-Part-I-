# Lab 8: Creating and Using Functions

## Objective

Learn how to:

- Define functions
- Call functions
- Pass parameters
- Return values
- Use functions for modular programming

## Tasks Completed

### Task 1
Created a function named `greet(name)`.

### Task 2
Modified the function to return a greeting message.

### Task 3
Used a `main()` function to call and display returned values.

## Output

Hello, Alice!

Hello, Bob!

## Concepts Used

- Functions
- Parameters
- Return Values
- String Formatting
- Code Reusability
- Modularity

## Benefits of Functions

- Reduce code duplication
- Improve readability
- Easier maintenance
- Reusable code blocks
