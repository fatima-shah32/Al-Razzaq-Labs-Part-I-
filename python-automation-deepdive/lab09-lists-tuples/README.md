# Lab 9: Working with Lists and Tuples

## Objective
Learn the differences between Python lists and tuples.

## Tasks Completed

### Task 1
Created a list containing five fruit names.

### Task 2
- Added an item using append()
- Removed an item using remove()
- Sorted the list using sort()

### Task 3
- Created a tuple
- Attempted modification
- Demonstrated tuple immutability

## Concepts Used

- Lists
- Tuples
- append()
- remove()
- sort()
- try-except
- TypeError

## Key Difference

### List
Mutable (can be modified)

### Tuple
Immutable (cannot be modified after creation)
