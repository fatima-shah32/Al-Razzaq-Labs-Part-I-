# Lab 23: Multi-threading Basics in Python

## Objective
Learn how to use Python threading module to run tasks concurrently.

## Features
- Create threads using threading.Thread
- Run multiple threads simultaneously
- Use join() to wait for completion

## Key Concepts
- Thread: Smallest unit of execution
- Concurrency: Running tasks in overlapping time

## Output Behavior
- Thread outputs are interleaved
- Order is not guaranteed due to concurrency

## Real-world Use Cases
- Web servers handling multiple requests
- Background tasks in applications
- Parallel I/O operations
