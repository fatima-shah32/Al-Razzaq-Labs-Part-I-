# Lab 6: Looping with for

## Objective

Learn how to use for loops in Python to iterate through ranges and lists.

## Tasks Completed

### Task 1
Printed numbers from 1 to 5 using the range() function.

### Task 2
Iterated through a list of fruits and displayed each item.

### Task 3
Counted the total number of items processed in the loop.

## Concepts Used

- for loop
- range()
- Lists
- Iteration
- Counters

## Sample Output

Numbers from 1 to 5:
1
2
3
4
5

List of Fruits:
apple
banana
cherry
date

Total number of items processed: 4
