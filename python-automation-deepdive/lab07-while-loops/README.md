# Lab 7: Looping with while

## Objective

Learn how to use while loops in Python.

## Tasks Completed

### Task 1
Printed numbers from 1 to 5 using a while loop.

### Task 2
Created an interactive loop that accepts user input.

### Task 3
Used break to terminate the loop when the user enters "exit".

### Graceful Termination
Displayed exit and termination messages using try-finally.

## Concepts Used

- while loop
- Infinite loops
- break statement
- User input
- try-finally
- Loop conditions
