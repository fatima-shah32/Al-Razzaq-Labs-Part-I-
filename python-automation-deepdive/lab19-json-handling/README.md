# Lab 19: Basic JSON Handling in Python

## Objective
Learn how to fetch, parse, and save JSON data using Python.

## Features
- Fetch JSON from API
- Convert JSON to Python dictionary
- Extract specific fields
- Save data to local JSON file

## API Used
https://jsonplaceholder.typicode.com/posts/1

## Output
- Full JSON response
- Extracted title and body
- Saved JSON file
