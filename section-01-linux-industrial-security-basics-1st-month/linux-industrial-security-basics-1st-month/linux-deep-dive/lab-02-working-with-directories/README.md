# Lab Name: 2. Working with Directories

## Objectives
- Understand basic directory operations
- Learn create, remove, move, rename directories

## Task 1: Create Directory
mkdir my_new_directory
ls

## Task 2: Remove Directory
rmdir my_new_directory
rm -r directory_with_contents

## Task 3: Move or Rename Directory
mv old_directory new_directory
mv new_directory parent_directory/

## Conclusion
Learned mkdir, rmdir, mv commands.
