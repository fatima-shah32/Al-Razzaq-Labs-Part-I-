# Lab 04 - Using Text Editors

## Objective
Learn how to use nano and vi text editors in Linux.

---

# Task 1 - nano Editor

## Open File

```bash
nano example.txt
```

## Add Content

```text
Hello, World!
This is a simple file edited using nano.
```

## Save and Exit
- CTRL + O
- ENTER
- CTRL + X

---

# Task 2 - vi Editor

## Open File

```bash
vi vi-example.txt
```

## Enter Insert Mode
Press:

```text
i
```

## Add Content

```text
Editing with vi is a bit different.
Remember to switch modes.
```

## Save and Exit
- ESC
- :wq
- ENTER
