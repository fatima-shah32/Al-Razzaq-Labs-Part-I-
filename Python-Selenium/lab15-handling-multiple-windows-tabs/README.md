# Lab 15: Handling Multiple Windows/Tabs

## Objective

Learn how to handle multiple browser windows and tabs using Selenium WebDriver.

## Tasks Completed

### Task 1
Opened multiple browser tabs.

### Task 2
Retrieved all window handles.

### Task 3
Switched between tabs using Selenium.

### Task 4
Printed titles and URLs from each tab.

### Task 5
Captured a screenshot for verification.

## Concepts Used

- Selenium WebDriver
- Browser Tabs
- Window Handles
- switch_to.window()
- switch_to.new_window()
- Screenshots
