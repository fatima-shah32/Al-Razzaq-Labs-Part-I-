# Lab 2: Locating Multiple Elements

## Objective

Learn how to locate multiple web elements using Selenium WebDriver and extract hyperlink information from a webpage.

## Tasks Completed

### Task 1
Initialized Selenium WebDriver using ChromeDriver.

### Task 2
Opened a webpage using the get() method.

### Task 3
Located all hyperlink elements using the TAG_NAME locator.

### Task 4
Printed link text and URL attributes.

### Task 5
Counted and displayed the total number of hyperlinks found.

### Task 6
Closed the WebDriver session properly.

## Concepts Used

- Selenium WebDriver
- Web Scraping
- HTML Hyperlinks
- Element Locators
- TAG_NAME Selector
- Python Automation
