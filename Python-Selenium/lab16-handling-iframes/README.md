# Lab 16: Handling iFrames

## Objective

Learn how to identify, switch to, interact with, and return from iFrames using Selenium WebDriver.

## Tasks Completed

### Task 1
Created a webpage containing an iFrame.

### Task 2
Switched Selenium context into the iFrame.

### Task 3
Entered text and clicked a button inside the iFrame.

### Task 4
Returned to the main page context.

### Task 5
Verified page elements and captured a screenshot.

## Concepts Used

- Selenium WebDriver
- iFrames
- switch_to.frame()
- switch_to.default_content()
- Element Interaction
- Screenshots
