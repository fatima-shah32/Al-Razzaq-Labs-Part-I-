# Lab 13: Checking & Selecting Radio/Checkboxes

## Objective
Learn how to automate radio buttons and checkboxes using Puppeteer.

## Tasks Completed

### Task 1
Installed Node.js project and Puppeteer.

### Task 2
Created HTML page with radio buttons and checkboxes.

### Task 3
Automated selection of:
- Radio button (Banana)
- Checkboxes (Reading, Travelling)

### Task 4
Extracted selected values from DOM.

## Concepts Used
- Puppeteer automation
- DOM selection
- Radio buttons
- Checkboxes
- page.click()
- page.evaluate()

## Sample Output
Selected radio: Banana  
Selected checkboxes: Reading, Travelling  
Selected values: radio-banana, checkbox-reading, checkbox-travelling
