# Lab 10: Taking Screenshots (Selenium)

## Objective
Learn how to capture screenshots using Selenium WebDriver.

## Tasks Completed

### Task 1
Set up Selenium WebDriver in headless mode.

### Task 2
Navigated to a web page using automation.

### Task 3
Captured basic screenshot of webpage.

### Task 4
Generated timestamped screenshot filenames.

### Task 5
Verified file creation using Python assertions.

## Concepts Used
- Selenium WebDriver
- save_screenshot()
- Python time module
- Timestamping files
- File verification using os.path.exists()
