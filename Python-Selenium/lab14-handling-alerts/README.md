# Lab 14: Handling Alerts

## Objective

Learn how to handle JavaScript alerts using Selenium WebDriver.

## Tasks Completed

### Task 1
Opened a webpage containing JavaScript alerts.

### Task 2
Triggered an alert using Selenium.

### Task 3
Switched to the alert and extracted its text.

### Task 4
Accepted and dismissed alerts.

### Task 5
Captured a screenshot after handling the alert.

## Concepts Used

- Selenium WebDriver
- JavaScript Alerts
- switch_to.alert
- Alert Acceptance
- Alert Dismissal
- Screenshots
