# Lab 1: Installing Selenium and WebDriver

## Objective
Set up Selenium with WebDriver and run a basic browser automation script.

## Tasks Completed

### Task 1: Install Selenium
Installed Selenium using pip and verified installation.

### Task 2: Install WebDriver
Installed ChromeDriver (or Chromium WebDriver) and configured system PATH.

### Task 3: Create Test Script
Created a Python script to launch a browser using Selenium.

### Task 4: Execute Script
Successfully executed automation script and verified browser launch.

## Concepts Used

- Selenium WebDriver
- Browser Automation
- Python Virtual Environment
- pip Package Manager
- ChromeDriver setup

## Sample Output

Selenium WebDriver successfully installed and running!
