# Lab 19: Running Selenium Headless

## Objective

Learn how to configure Selenium WebDriver to run in headless mode and automate browser tasks without a graphical user interface.

## Tasks Completed

### Task 1

Configured ChromeOptions for headless execution.

### Task 2

Opened a webpage using Selenium WebDriver.

### Task 3

Captured a screenshot in headless mode.

### Task 4

Measured page load time.

### Task 5

Compared headless mode with normal browser execution.

* Selenium WebDriver
* Chrome Headless Mode
* Browser Automation
* Performance Measurement
* Screenshots
* Python Automation
