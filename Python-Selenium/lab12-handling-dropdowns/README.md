# Lab 12: Handling Dropdowns (Selenium)

## Objective
Learn how to interact with dropdown menus using Selenium Select class.

## Tasks Completed

### Task 1
Created local HTML page with dropdown.

### Task 2
Loaded page using Selenium WebDriver.

### Task 3
Selected dropdown values using:
- Visible Text
- Value attribute

### Task 4
Retrieved selected option.

### Task 5
Validated selection using assertion.

## Concepts Used
- Selenium WebDriver
- Select Class
- find_element(By.ID)
- select_by_visible_text()
- select_by_value()
- first_selected_option
- Assertions
